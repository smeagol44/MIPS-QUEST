# MIPS Quest

**The N64 ROM-Hacking Adventure** — learn MIPS by repairing a playable digital world, then apply those skills to verified, user-supplied Nintendo 64 ROMs.

> Project status: Milestone A — foundation in progress. The playable adventure and real ROM patcher are future milestones.

See the Milestone A pull request for the initial application, interfaces, tests, and project documentation.

No commercial ROMs or proprietary game assets belong in this repository.
