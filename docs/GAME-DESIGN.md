# Game Design — The Broken Machine

**Design intent:** Assembly must be the player's means of affecting the world, not a detached set of quizzes.

## Vision

A retro-futuristic digital universe is malfunctioning. A Logic Lens reveals executable code behind doors, robots, teleporters, memory vaults and control mechanisms. Player interventions manipulate real simulated machine state and produce tangible world responses.

## Campaign progression

- World 0 — The Awakening: registers, instructions and step execution.
- World 1 — The Bit Mines: binary, hexadecimal, flags, signedness and arithmetic.
- World 2 — The Memory Vault: memory, addresses, alignment, pointers and stacks.
- World 3 — The Branching Factory: conditions, loops, branch and jump delay slots.
- World 4 — The Call Stack: functions, calling conventions, argument and return registers.
- World 5 — The Corrupted Archive: disassembly, tracing and reverse engineering.
- World 6 — The Cartridge Forge: ROM mapping, binary modifications, code caves, hooks, relocation and patch safety.
- World 7 — The Core: integrated debugging and advanced architectural behavior.

Then verified practical game campaigns, beginning with Super Mario 64. Later games and PlayStation require independent compatibility verification.

## Vertical slice (NOT yet implemented)

World 0: (1) wake a beacon using register arithmetic; (2) unlock a door through store operations; (3) choose a corridor with branches; (4) defeat the Gatekeeper through multi-state debugging.

## Design principles

- Progressive disclosure for complete beginners; define every prerequisite in context.
- Immediate feedback from the actual emulator state and event stream.
- Alternative solutions accepted through behavior-based validators, not exact text matching.
- Optional discoveries and mastery rewards, never compulsory grinding.
- Clear distinction between simulated teaching addresses and real hardware.
- Keyboard accessibility, color-independent status cues and reduced motion.
- Original art and audio; no redistributed commercial assets.
